# ロボっこの組み立て説明書

## 最初にお読みください

- 3Dプリント部品は**高温で変形**します。
- ATOMの画面は**強く押し込むと割れることがあります**。軽く押してください。
- サーボへの負荷でATOMが再起動することがあります。**誤った取り付けや負荷をかけたままの運転は故障の原因**になるため、引っかかったら電源を切ってください。

**マカロンちゃんはバッテリー必須（組み立て後のUSB給電は非対応）。おばけねこはUSB・対応バッテリーの両方で使えます。**

配線・電池の着脱・接着は**電源OFF**で行います。USBを抜き、バッテリーのスイッチもOFFにしてください。

## 手順3：ホーンを付けたあと、もう一度確認

1. 往復していたら画面を1回押し、完全に止まるまで待ちます。
2. **ダブルクリックでホーンを取り付ける位置に合わせます。** ↑が出て動きが止まったら、ホーンを真上に向けて取り付けます。電源ONのままでも取り付けられます。
3. **もう一度ダブルクリックし、止まったときにホーンが真上か確認**します。ずれていたら付け直して再確認します。
4. 向きが合ったら電源を切り、ヒンジをソケットに固定します（接着推奨）。

マカロンのつっかえ棒は**ふたの内側**へ接着。おばけねこは足をかぶせ、ひっくり返して完成です。
