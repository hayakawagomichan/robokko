それぞれ **A4用紙1枚の両面（2ページ）** です。

PDFを開いてダウンロードし、**A4・両面・長辺とじ・実際のサイズ（100%）** で印刷してください。
細かな接着位置や配線を見分けやすい、カラー印刷がおすすめです。
配線は線色に加えて「GND・5V・G2」の表示でも確認してください。

## 始める前に

- 未書き込みのATOM S3Rは、[READMEの書き込み手順](../README.md#はじめに)から準備します。
- 部品をこれから購入する場合は、[買い物リスト](shopping-list.md)を確認してください。
- 配線・ホーンの取り付け・接着は電源を切って行います。USB給電ならケーブルを抜き、バッテリー使用時はスイッチを切ります。
- 写真に写る部品の色は、キットにより異なる場合があります。内容物の写真には、別途用意するATOM S3Rやバッテリーも含まれます。

## 手順3：ホーンを付けたあと、もう一度確認

1. 電源を入れて画面を素早く2回押し、「↑」を出します。
2. サーボが止まったら電源を切り、ホーンが真上を向くように取り付けます。
3. 再び電源を入れ、画面を素早く2回押します。**動きが止まってから、ホーンが真上を向いているか確認**します。
4. ずれていたら電源を切って付け直し、もう一度確認します。向きが合ってから電源を切り、ヒンジを固定します。

電源を入れた直後にもサーボは動きます。確認するのは、ダブルタップして停止したあとの向きです。

マカロンちゃんは、つっかえ棒を**ふたの内側**に接着してから閉じます。
おばけねこは、コードを収めたあと足をかぶせ、ひっくり返して完成です。
