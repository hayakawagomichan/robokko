# 3Dプリントで部品を作る

**3Dプリントした部品は、高温で変形します。**

作りたいキャラクターの部品と[共通部品](#common)を印刷してください。電子部品は[買い物リスト](shopping-list.md)、組み立ては[説明書](assembly.md)へ。

## ダウンロード

下のリンクで個別に保存できます。一式なら[トップページ](../README.md)の **Code → Download ZIP** でダウンロードし、解凍後の `models` フォルダを開きます。

| 形式 | 使い方 |
| --- | --- |
| **STL** | 部品の形。自分のプリンター用のスライサーで印刷設定を作ります。 |
| **3MF** | 形・配置・印刷条件。収録データはP2S用です。Bambu Studioで**プロジェクトとして**開きます。 |
| **gcode.3mf** | P2S用の計算済み印刷命令。編集用の形状は入っていません。 |

## 印刷のポイント

- **mm・倍率100%**で読み込みます。
- **ヒンジは、なるべく細いノズルで細かく印刷**してください。
- 印刷方向・積層・サポートは、下の3MFを参考に、自分の機種と材料に合わせて設定します。
- 印刷後はサポートを除去します。マカロンの軸穴も確認してください。

### Bambu Lab P2S用：設定付き3MF

4ファイルとも **P2S・0.4 mmノズル・積層0.24 mm・PLA** の設定です。必要な個数に減らして使えます。STLと重複して印刷する必要はありません。

| 3MF | 収録内容 |
| --- | --- |
| [マカロン：本体・4台分](../models/印刷設定_BambuP2S専用/マカロン_本体_4台分.3mf?raw=true) | 本体4個 |
| [マカロン：ふたとつっかえ棒・4台分](../models/印刷設定_BambuP2S専用/マカロン_ふたとつっかえ棒_4台分.3mf?raw=true) | ふた4個＋つっかえ棒4個 |
| [マカロン：ホイップと軸・4台分](../models/印刷設定_BambuP2S専用/マカロン_ホイップと軸_4台分.3mf?raw=true) | ホイップ8個＋軸4個 |
| [バッテリーなし用スペーサー・30個](../models/印刷設定_BambuP2S専用/バッテリーなし用スペーサー_30個.3mf?raw=true) | スペーサー30個 |

おばけねこの外装・ソケット、マカロンのソケットはSTLのみです。

### ヒンジと台：印刷例（スライス済み）

[ヒンジと組み立て用の台.gcode.3mf](../models/参考のみ_スライス済み/ヒンジと組み立て用の台_P2S_0.4mmノズル.gcode.3mf?raw=true)

収録条件は **P2S・0.4 mmノズル・積層0.16 mm**。より細いノズルなどに変更するときは、上のヒンジ・台のSTLからスライスし直してください。
**他機種・異なるノズル構成に、この印刷命令をそのまま送らないでください。**
