# なかよし！ロボっこキット — ATOM S3R ファームウェア

**かわいいから、つくってみたい。気づいたら、ちゃんとロボットをつくってた。**

「なかよし！ロボっこキット」の、顔表示とSG90サーボを制御する基本プログラムです。
ATOM S3Rのボタンと傾きセンサーに反応して、顔や動きが変わります。

このリポジトリでは、まず **プログラム・書き込み手順・配線手順** を公開しています。
3Dデータ・機構データ・組立図はまだ含まれていません。

## 用意するもの

- M5Stack ATOM S3R（画面付き）
- SG90サーボモーター
- Groveケーブルと、サーボへ正しく接続できる変換アダプタ／配線
- データ通信可能なUSBケーブルとPC
- PlatformIO（Arduinoフレームワークを使用）

このプログラムを書き込むと、本体の既存プログラムは置き換わります。
UIFlow2用のプロジェクトではありません。

## ファイル

- `src/main.cpp`: 動作プログラム
- `include/img_*.h`: 5種類の顔画像
- `platformio.ini`: ATOM S3R用のビルド設定
- `build.ps1`: Windowsの日本語パスを避けてビルド・書き込みする補助スクリプト

## 最初の書き込み（Windows）

PlatformIO CoreまたはVS CodeのPlatformIO拡張が必要です。
まずこのリポジトリをダウンロードして展開してください。

1. 最初はサーボを外し、ATOM S3R本体のみをデータ通信可能なUSBケーブルでPCに接続します。
2. PowerShellでこのフォルダを開きます。
3. `./build.ps1` でビルドします。
4. デバイスマネージャーで本体のCOM番号を確認します。
5. `./build.ps1 -Upload -Port COM4` で書き込みます。COM4は例なので、自分のPCの番号に置き換えてください。
6. 顔が出ること、クリック・傾き・シェイクへの反応を確認します。

接続できない場合は本体のリセットボタンを約2秒長押しし、内部の緑LEDが点灯したら離してダウンロードモードにします。COM番号が変わった場合は指定し直してください。

この補助スクリプトは英数字の一時フォルダにソースをコピーしてPlatformIOを実行します。生成されたbinは `output/firmware` にコピーします。WindowsのESP32ツールチェーンでは、日本語パスから直接ビルドすると失敗する場合があります。

macOS/Linuxや英数字のみのパスでは、通常のPlatformIO操作も利用できます。

```sh
pio run
pio run -t upload --upload-port <port>
```

## 配線と動作確認

必ずUSB電源を外してから配線します。

| ATOM S3RのGrove端子 | 接続先 |
| --- | --- |
| GND（黒） | サーボGND（茶または黒、製品表示で確認） |
| 5V（赤） | サーボ電源 |
| G2 / GPIO2（黄） | サーボ信号 |
| G1 / GPIO1（白） | 使用しない |

起動するとサーボへ65°を指示します。最初は機構から外したサーボで確認してください。
プログラムの可動範囲は20〜65°です。機構との干渉を確認せずに範囲を広げないでください。

| 操作 | 主な動作 |
| --- | --- |
| 1回クリック | 往復動作の開始・停止。停止時は65°へ戻る |
| 2回クリック | 20°と65°への単発移動、矢印表示。往復中は移動先から往復を継続 |
| 往復中に横向きで2秒 | 65°へ戻って休止。縦向きにすると再開 |
| 停止中に横向き | 寝顔を表示 |
| 軽く振る | 渦巻き顔を短時間表示（矢印表示中は矢印が優先） |

## 固定した環境

- PlatformIO espressif32 6.7.0 / Arduino-ESP32 2.0.16
- M5Unified 0.2.23 / M5GFX 0.2.30
- ESP32Servo 1.2.1（Arduino 2.x向け）
- ESP32-S3、8MB Flash、8MB Octal PSRAM

設定・端子配置・ダウンロードモードの参照: [M5Stack公式 ATOM S3R](https://docs.m5stack.com/en/core/AtomS3R)
